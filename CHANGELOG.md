# Changelog

## XFCE development branch — October 2026

- Publish the real display, touch, GUI startup, window-bounds and keyboard helpers.
- Document XFCE bring-up and the old-kernel pixbuf/menu compatibility fixes.
- Publish audio routing, volume/OSD, Bluetooth startup, power-key, front-key and
  accelerometer integration source with installation paths.
- Document NetworkManager/nm-applet and Blueman ownership and reboot persistence.
- Recover the working GCC 15 compatibility changes, LZMA/USB/HCIUART configuration
  and the sprdfb resume patch; separate optional, unflashed changes.
- Record hardware support, recovery boundaries, build limits and experimental
  SR352 camera work. No new rootfs, kernel release or media is published.

## September 2026

Framebuffer node/colour/scanout bring-up, physical Xorg and touch, xmessage,
Openbox, XFCE 4.20, menu compatibility, automatic GUI boot and window bounds.

## June 2026

Initial headless Alpine/postmarketOS system with static-init boot, USB RNDIS,
interactive SSH and persistent boot repairs. The original downloadable image
belongs to this stage. See [development history](docs/development/history.md).
