\# Samsung Galaxy Young 2 postmarketOS documentation



This folder contains detailed documentation for the Samsung Galaxy Young 2 postmarketOS development.



The root readme you see on the mainpage is the short public overview of the project.  

The files in this folder are for longer technical notes, installation details, troubleshooting, partition information, boot notes, and references.



This documentation is based on testing with the Samsung Galaxy Young 2 SM-G130HN (If you have a different variant, this may not work.)



This is an experimental bring-up. It is not a finished daily-driver port.



\---



\## Current bring-up state



The current setup can boot postmarketOS/Alpine userspace and provide access over USB networking.



Current practical status:



Boots: yes

Linux userspace: yes

Framebuffer output: yes

USB networking: yes

SSH root shell: yes

Daily-driver usable: no
